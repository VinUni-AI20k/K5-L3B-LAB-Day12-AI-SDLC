# Tài nguyên đồ họa & âm thanh cho `chonoi.live` (`chonoi/web/assets/`)

Thư mục này là nơi đặt hình nền, spritesheet và nhạc nền cho giao diện `chonoi.live`.
Client `chonoi/web/index.html` tự động thử tải các file dưới đây; **nếu file nào chưa được thêm vào, game tự động vẽ bằng đồ họa Canvas 2D mặc định** (không bị lỗi).

## Danh sách tên file chuẩn để thêm sau

| Tên file trong `chonoi/web/assets/` | Loại | Công dụng |
|---|---|---|
| `gather_bg.png` | Ảnh nền | Hình nền cảnh sông Chín Khúc buổi sáng (`mode: gather`) |
| `quan_bg.png` | Ảnh nền | Hình nền cảnh nhà bè Má Tư buổi tối (`mode: quan`) |
| `ut_sen.png` | Sprite / Spritesheet | Hình nhân vật Út Sen (bơi/lặn và đi bộ bưng món) |
| `fish_ca_linh.png` | Sprite | Hình đàn cá linh (`ca_linh`) |
| `fish_ca_loc.png` | Sprite | Hình cá lóc (`ca_loc`) |
| `node_bong_dien_dien.png` | Sprite | Hình bụi bông điên điển (`bong_dien_dien`) |
| `node_bong_sung.png` | Sprite | Hình bụi bông súng (`bong_sung`) |
| `stove.png` | Sprite | Hình bếp nấu (`B1`) |
| `table.png` | Sprite | Hình bàn khách (`T1`) |
| `customer.png` | Sprite | Hình khách ăn tại quán |
| `bgm_gather.mp3` | Nhạc nền | Nhạc nền buổi sáng lặn sông (bật/tắt bằng phím `M`) |
| `bgm_quan.mp3` | Nhạc nền | Nhạc nền buổi tối mở quán chợ nổi (bật/tắt bằng phím `M`) |
