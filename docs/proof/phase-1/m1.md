# Bằng chứng Phase 1 — M1

[Tiêu chí chấp nhận M1](../../plan/phase-1-m1.md) · [Test headless M1](../../../tests/test_gather_m1.py)

| AC | Quan sát | Kết quả |
|---|---|---|
| M1-AC1 | Smoke test kiểm tốc độ sau ramp, đảo hướng, hướng mặt, chặn mép và vận tốc sau chặn. | Đạt |
| M1-AC2 | `dive` và `surface` chỉ xuất hiện khi đổi vùng. Vị trí trong event khớp snapshot cùng tick. | Đạt |
| M1-AC3 | Với một tick oxy ban đầu và không điều khiển, `oxygen_empty` ở tick 1, `choke` ở tick 60 và 120. | Đạt |
| M1-AC4 | Nổi đúng tick dự kiến mất Máu thì bộ đếm ngạt về 0, Máu giữ nguyên và oxy hồi đến trần. | Đạt |
| M1-AC5 | Ngất cùng tick tương tác tại bến và hết giờ. Thứ tự event là `choke` → `faint` → `gather_end`. Danh sách đồ mất theo LIFO, file kho rỗng và lý do cuối là `fainted`. | Đạt |

Lệnh chuẩn của repo:

```bash
PYTHONPATH=tests:. python3 -m unittest discover -s tests -v
```

Kết quả chạy trên Windows với Python 3.15.2: cả 4 test M1 báo thiếu hành vi trước khi triển khai. Sau khi triển khai, toàn bộ 42 test đạt trong 9,639 giây. Alias `python3.exe` không khởi chạy được trên máy này, nên lần chạy dùng `PYTHONPATH=tests;.` và thay `python3` bằng `sys.executable` khi gọi tiến trình headless trong bộ test.
