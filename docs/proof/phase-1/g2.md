# Kiểm chứng lát G2

Trên Windows, smoke test dùng `python3` theo hợp đồng và gặp lỗi `WinError 1920`. Chạy lại với Python hiện hành cho tiến trình headless, giữ nguyên các file test và hợp đồng.

```powershell
$env:PYTHONPATH = 'tests;.'
python -c "import sys, unittest, helpers; helpers.headless_cmd = lambda: [sys.executable, '-m', 'chonoi.headless']; suite = unittest.defaultTestLoader.discover('tests'); sys.exit(not unittest.TextTestRunner(verbosity=2).run(suite).wasSuccessful())"
```

37 test đạt, gồm 5 test G2 kiểm tra hái ở ranh 2 m, mọc lại đúng 1.200 tick, ưu tiên bến, điều kiện mặt nước và dưới nước, sức chứa giỏ, hòa theo ID và hồi chiêu 30 tick.

N5, N6 và cá kèo chờ PO chốt cập nhật hợp đồng theo mục 2 của [Clarify](../../clarify.md).
