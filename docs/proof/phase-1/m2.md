## 2. Bằng chứng kiểm thử Smoke Hộp Đen (PRD-0 mục G)

Thực hiện lệnh tích hợp 2 tiến trình theo đúng kịch bản mẫu của PRD-0 mục G:
```bash
python -m chonoi.headless --mode gather --seed 42 --scenario docs/proof/phase-1/m2_dock_scenario.json --inputs docs/proof/phase-1/m2_dock_inputs.json --ticks 1 --out docs/proof/phase-1/m2_gather_dock.jsonl --inventory-out docs/proof/phase-1/m2_catch.json
python -m chonoi.headless --mode quan --seed 42 --inventory docs/proof/phase-1/m2_catch.json --ticks 1 --out docs/proof/phase-1/m2_quan_from_catch.jsonl
```

### Kết quả đối chiếu File Kho:
- **File mẫu hợp đồng ([inventory.sample.json](../../contracts/inventory.sample.json)):**
  ```json
  {"items":{"bong_sung":2,"ca_loc":1}}
  ```
- **File thực tế tiến trình `gather` xuất ra ([m2_catch.json](m2_catch.json)):**
  ```json
  {"items":{"bong_sung":2,"ca_loc":1}}
  ```
  $\rightarrow$ **Khớp chính xác từng byte!**

- **Snapshot tiến trình `quan` đọc kho nạp vào ([m2_quan_from_catch.jsonl](m2_quan_from_catch.jsonl)):**
  ```json
  {"type":"snapshot","tick":0,...,"stock":{"bong_sung":2,"ca_loc":1},...}
  ```
  $\rightarrow$ **Quán nhận đầy đủ 100% kho từ gather.**
